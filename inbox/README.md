# Inbox

Kiến thức còn sơ khai — chưa đủ để thành tài liệu trong `docs/`.

Một file một ngày: `YYYY-MM-DD.md`. Ghi 3 dòng cũng được, không cần trau chuốt, không
cần quyết định nó thuộc thư mục nào.

**Cuối tuần dọn.** Mỗi mục hoặc lên `docs/` thành tài liệu, hoặc xoá. Inbox tồn đọng
quá 2 tuần là dấu hiệu đang ghi thứ mình không thật sự cần.
