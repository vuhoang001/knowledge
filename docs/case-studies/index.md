# Case Studies

Chưa có bài nào.

## Khuôn một case study

1. **Bối cảnh** — hệ thống nào, dữ liệu gì, ai dùng.
2. **Triệu chứng** — cái gì sai, ai phát hiện, phát hiện bằng cách nào.
3. **Giả thuyết sai lúc đầu** — phần giá trị nhất, đừng bỏ.
4. **Nguyên nhân thật** — kèm bằng chứng (log, query, output).
5. **Cách sửa** và **cách phòng** — test nào, cảnh báo nào.
6. **Bài học rộng hơn ca này**.

Bỏ mục 3 là biến case study thành tài liệu hướng dẫn — mất đúng phần dạy được nhiều nhất.
