# Exercises — Design Patterns

Really run, with a box to paste your output. If you can't run it, you haven't learned it.

| # | Exercise | What you can do afterwards | Duration |
|---|---|---|---|
| 1 | [Escalating from a `switch` to Strategy + Decorator](refactor-switch-sang-pattern.md) | Walk four escalating steps on the same problem, and know **which step to stop at** — including the case where decorator ordering is off by 22,500 VND | ~30 minutes |

The lab runs on .NET 10+ as a file-based app (`dotnet run <name>.cs`), with **no project to
create**. Put the file outside this repo, for example `~/Documents/learn-lab/patterns`.

**An empty *Yours* box means it hasn't been run.** Only fill in `verified_at` once you've run it.
